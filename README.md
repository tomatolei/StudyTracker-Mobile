# 📚 StudyTracker-Mobile（学习监督）

一款面向手机端的本地学习记录工具，用来记录孩子每天的作业完成情况、学习时长、异常波动和周报复盘。

当前版本：**v2.1.4**  
更新时间：**2026-03-20**

---

## ✨ 当前核心功能

### 1. 首页记录更快
- 今日概览：显示总作业、已完成、剩余、完成率、最近学习天数
- 快速操作：一键布置作业、查看历史、打开数据管理
- 今日提醒：未设置孩子信息、未布置作业、完成情况提醒
- 异常提醒：汇总今日异常数、近 7 天异常数、重点关注科目
- 快速录入：支持 **预期 / 平均 / +15 / +30 / 回车提交**

### 2. 作业记录更完整
- 按科目布置当天作业
- 支持自定义科目、Emoji 图标、主题颜色
- 记录实际用时并自动同步到历史
- 根据历史平均时长做异常检测
- 异常时可填写备注，后续复盘可回看

### 3. 历史和复盘更清楚
- 首页有“当日完成历史”
- 独立“完成历史”弹窗，可按天查看、删除单条或整天记录
- 报告页新增“本周复盘结论”
- 自动给出：
  - 本周亮点
  - 最稳定科目
  - 重点关注
  - 与上周对比趋势

### 4. 数据管理更可靠
- **备份数据**：真实保存 `.json` 文件
- **恢复数据**：支持先选文件、先预览、再恢复
- 恢复支持两种模式：
  - 覆盖恢复
  - 合并恢复
- **Excel 导出**：真实生成 `.xlsx` 文件
- 安卓优先保存到 `Download/Downloads`，失败时自动回退到应用可访问目录

### 5. 手机端 UI 持续紧凑化
- 首页卡片、按钮、统计区整体收紧
- 选择今日作业面板更紧凑
- 添加新科目弹窗更紧凑
- 编辑孩子信息弹窗更紧凑
- 年级选择已从系统下拉改成 **按钮网格**，更适合手机
- 完成历史列表与弹窗已重排，减少一行塞太多信息的混乱感

## 📦 导出与恢复

### JSON 备份
导出的备份文件包含：
- `schemaVersion`
- `appVersion`
- `exportTime`
- `currentChild`
- `childForm`
- `childMood`
- `childAvatar`
- `todayHomework`
- `homeworkHistory`
- `subjectConfig`
- `customSubjects`

文件名示例：
```text
学习进度备份_2026-03-20_03-25-10.json
```

### Excel 导出
Excel 为真实 `.xlsx` 文件，包含 4 个工作表：
1. 基本信息
2. 每日汇总
3. 科目统计
4. 作业明细

文件名示例：
```text
洪书豪_学习统计_2026-03-20_03-25-10.xlsx
```

### 恢复流程
1. 选择备份文件
2. 查看导入预览
3. 选择“覆盖恢复”或“合并恢复”
4. 确认导入

## ⚙️ 核心规则

### 年龄自动计算
```javascript
年龄 = 当前年份 - 出生年份 - (当前月份 < 出生月份 || (当前月份 == 出生月份 && 当前日期 < 出生日期) ? 1 : 0)
```

### 年级自动匹配
当前内置年级范围：
```text
一年级、二年级、三年级、四年级、五年级、六年级、初一、初二、初三、高一、高二、高三
```

### 异常检测
```javascript
异常 = |当前用时 - 历史平均用时| / 历史平均用时 > 0.3
```
即：偏离历史平均值 **30% 以上** 视为异常。

## 🤖 GitHub Actions 自动构建 APK

工作流文件：
```text
.github/workflows/android-build.yml
```

当前统一版本：
- `APP_VERSION: 2.1.4`
- `APP_VERSION_CODE: 214`

当前统一分支：
- `main`

上传脚本：
```text
upload-to-github.bat
```
支持双击运行，读取 `.git_token`，只提交主项目源码，不提交 Android Studio 构建产物。
