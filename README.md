# 📚 儿童学习进度监督系统

一款专为儿童设计的学习进度管理应用，帮助孩子培养良好的学习习惯，让家长随时了解孩子的学习情况。

## ✨ 主要功能

### 🏠 首页功能
- **孩子信息管理**：显示孩子姓名、年级、年龄、性别，支持自定义头像
  - 🎂 出生日期自动计算年龄和年级（3 岁小班到 17 岁高三）
  - ✏️ 支持手动调整年级（适配上学早/晚、跳级等情况）
- **今日心情**：4 种心情表情可选（😃😐😔😤），记录孩子每天的学习心情
- **作业统计**：实时显示总作业数、已完成、进行中、总用时
- **作业管理**：
  - 分科目布置作业（支持自定义科目）
  -  快捷时间输入：滑动条调节 + 快捷按钮（预期/平均/15/30/45/60）
  - 输入实际用时，自动对比历史平均时间
  - 异常时间自动提示填写备注
  - 完成历史随时查看

### 📊 统计报告
- **本周摘要**：5 个核心指标（总作业、总分钟、学习天数、日均分钟、日均作业）
- **7 天趋势**：双柱状图展示最近 7 天的作业量和学习时长变化
- **甜甜圈饼图**：
  - 作业数量占比图：直观显示各科目作业数量百分比，图例每行 2 个排列
  - 学习时长占比图：直观显示各科目学习时长百分比，图例每行 2 个排列
- **学科分布**：卡片式展示各科目作业总数量，每行 4 个，颜色与科目主题色一致

### ⚙️ 系统设置
- **科目配置**：
  - ➕ 支持无限添加自定义科目（物理、化学等）
  - 🎨 自定义科目名称、Emoji 图标、主题颜色
  - 🗑️ 可删除不需要的科目（语数英不可删除）
  - 📝 每个科目可配置多个作业模板和预计时间
- **孩子信息**：随时修改孩子基本信息、出生日期和头像
- **数据管理**：
  - 备份数据到本地（JSON 格式，自动保存文件）
  - 从备份恢复数据
  - 📊 导出 Excel 统计报表（真实 `.xlsx` 文件，4 个工作表：基本信息、每日汇总、科目统计、作业明细）
  - 清空历史/当天/全部数据
- **使用说明**：内置完整的功能使用文档和核心算法说明

## 📱 打包成 APK

### 前置准备

1. **准备图标（可选）**
   - 尺寸：512x512 或 1024x1024 像素
   - 格式：PNG（支持透明背景）
   - 命名：`icon.png`
   - 位置：`resources/android/icon/icon.png`

2. **上传到 GitHub**
   ```
   StudyTracker-Mobile/
   ├── www/
   │   └── index.html          # 主程序（必需）
   ├── config.xml              # Cordova 配置（必需）
   ├── .github/
   │   └── workflows/
   │       └── android-build.yml   # 打包流程（必需）
   ├── resources/
   │   └── android/
   │       └── icon/
   │           └── icon.png    # 应用图标（可选）
   └── README.md               # 本文件
   ```

### 打包步骤

1. **上传文件**
   - 将上述文件上传到你的 GitHub 仓库

2. **运行打包**
   - 在 GitHub 页面点击 **"Actions"** 标签
   - 选择 **"Build Signed Android APK"**（`android-build.yml`）工作流
   - 点击 **"Run workflow"** 按钮
   - 建议选 `main` 分支（workflow 同时监听 `master` 以兼容旧推送）

> Tip: `upload-to-github.bat` 目前会把分支名规范为 `main`，临时用你在 `.git_token` 里的 PAT 推送，并在推送后恢复远程 URL（不再把 token 记录在 `.git/config`）。

3. **下载 APK**
   - 等待打包完成（首次约 3-5 分钟）
   - 点击生成的记录进入详情页
   - 在 **"Artifacts"** 区域下载 `apk.zip`
   - 解压后得到 `app-debug.apk`

4. **安装使用**
   - 将 APK 传到手机
   - 允许安装未知来源应用
   - 安装并打开

### 更新版本

修改代码后，只需：
1. 提交更改到 GitHub
2. 重新运行 Actions 工作流
3. 下载新的 APK 覆盖安装

## 🛠️ 本地开发

### 使用 Cordova 本地调试

```bash
# 安装 Cordova
npm install -g cordova

# 创建项目
cordova create app com.leilei.studytracker 学习监督
cd app

# 替换文件
cp ../www/index.html www/index.html
cp ../config.xml config.xml

# 添加 Android 平台
cordova platform add android

# 运行调试
cordova run android
```

## 📋 配置文件说明

### config.xml

```xml
<widget id="com.leilei.studytracker"
        version="2.1.3"
        android-versionCode="213"
        xmlns="http://www.w3.org/ns/widgets"
        xmlns:cdv="http://cordova.apache.org/ns/1.0">
    <name>学习监督</name>
    <content src="index.html" />
    <icon src="resources/android/icon/icon.png" />
</widget>
```

- `id`: 应用包名
- `version`: 应用显示版本号
- `android-versionCode`: Android 内部版本号（用于升级判断）
- `content`: 启动页面
- `icon`: 应用图标路径

## 📊 数据存储

### 本地存储（localStorage）

所有数据保存在本地，包括：
- `currentChild`: 孩子信息（含出生日期、年龄、年级）
- `childMood`: 今日心情
- `todayHomework`: 当天作业
- `homeworkHistory`: 历史完成记录
- `subjectList`: 科目列表（支持自定义科目）
- `subjectConfig`: 科目作业配置
- `childAvatar`: 孩子头像（Base64 编码）

### 数据备份

- **导出**：生成 JSON 备份文件，并自动保存到本地存储
- **导入**：选择备份文件，恢复所有数据
- **Excel 导出**：生成结构化 Excel 报表（真实 `.xlsx`，4 个工作表）
- **保存位置**：安卓优先保存到 `Download/Downloads`，不可用时回退到应用可访问目录；浏览器环境保存到默认下载目录
- **建议**：定期备份，防止数据丢失

## 🎯 使用技巧

### 1. 快捷时间输入 ⚡
- **最快方式**：点击「平均」或「预期」按钮 → 点提交（2 步完成）
- **滑动调节**：拖动滑块快速设置用时，步长 5 分钟
- **常用时间**：点击 15/30/45/60 按钮一键选择
- **精确输入**：直接在输入框输入具体数值

### 2. 异常时间检测
- 系统会自动计算每项作业的历史平均用时
- 当实际用时偏离平均值 **±30%** 时，会提示填写备注
- 首次完成的作业不会触发异常检测

### 3. 自定义科目
- 进入设置→科目配置→点击「+ 添加科目」
- 填写科目名称、选择 Emoji、挑选主题颜色
- 保存后自动生成默认作业模板（练习、试卷）
- 新科目自动出现在作业选择、报告统计等所有位置

### 4. 年龄年级自动计算
- 编辑孩子信息时选择出生日期
- 系统自动计算实岁和对应年级（国内标准入学年龄）
- 支持手动调整年级，手动调整后优先级最高

### 5. Excel 导出
- 点击设置→「📊 导出学习统计（Excel）」
- 自动生成真实 `.xlsx` 文件并保存到本地
- 安卓优先保存到 `Download/Downloads`；如系统限制该目录，则自动回退到应用可访问目录
- 浏览器环境会保存到浏览器默认下载目录
- 文件名格式：`孩子姓名_学习统计_日期.xlsx`
- 包含 4 个工作表：基本信息、每日汇总、科目统计、作业明细

## ⚙️ 核心算法

### 1. 年龄自动计算
```javascript
年龄 = 当前年份 - 出生年份 - (当前月份 < 出生月份 || (当前月份 == 出生月份 && 当前日期 < 出生日期) ? 1 : 0)
```
自动考虑生日是否已过，每年生日当天自动增长年龄。

### 2. 年级自动匹配
```
3 岁→小班 / 4 岁→中班 / 5 岁→大班 / 6 岁→一年级 / 7 岁→二年级 / 8 岁→三年级 / 9 岁→四年级 / 10 岁→五年级 / 11 岁→六年级 / 12 岁→初一 / 13 岁→初二 / 14 岁→初三 / 15 岁→高一 / 16 岁→高二 / 17 岁→高三
```

### 3. 异常检测
```javascript
异常 = |当前用时 - 历史平均用时 | / 历史平均用时 > 0.3
```
偏离 30% 以上判定为异常，需填写备注说明原因。

## ⚠️ 注意事项

1. **数据安全**
   - 所有数据存储在本地，卸载应用会丢失数据
   - 建议每周备份一次重要数据
   - 更换设备时先备份再迁移

2. **头像大小**
   - 上传的头像会自动压缩到 200px 宽度
   - 压缩后约几十 KB，不会占用太多空间
   - 支持 JPG、PNG 等常见图片格式

3. **浏览器兼容**
   - 推荐使用 Chrome、Edge 等现代浏览器
   - 部分老版本浏览器可能不支持某些功能
